# Heritage Notes: verified sources and boundaries

Checked online during the targeted fix pass. Facts are short original paraphrases. No third-party photographs or diagrams were imported. The game is not a reconstruction of a real temple.

## Research for the report
[Clark, Tanner-Smith and Killingsworth (2016), Digital Games, Design, and Learning: A Systematic Review and Meta-Analysis](https://pmc.ncbi.nlm.nih.gov/articles/PMC4748544/), Review of Educational Research, 86(1), 79–122. DOI: 10.3102/0034654315582065. The review reports an average learning advantage across the studies it analysed; design and context matter. It does not test this game or prove a heritage-learning outcome here. Check each reference before submitting.

## Cultural display decision
The latest brief requests no real deity likeness. The original shrine model remains intact in the project and is not interactable; its renderer is hidden at runtime. The old loading_b_thieves image depicts a deity being carried: it is excluded from rotation, with the source file preserved. No sacred image becomes a recovery object. Older screenshots containing those depictions must not be used as the final cultural presentation.
